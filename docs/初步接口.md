### 5.1 创建模拟任务（触发自动化建模流程）

**接口**: `POST /simulation-jobs`  
**认证**: 需要  
**说明**: 后台自动执行：分子数量计算 → Packmol 构型生成 → Moltemplate 拓扑构建 → LAMMPS 脚本生成 → 提交到计算引擎队列。

**请求体**:

```json
{
  "jobName": "EC-DMC-LiPF6 高温测试",
  "systemId": 5001,
  "targetProperties": ["density", "conductivity", "viscosity", "solvation_structure"],
  "simulationConfig": {
    "ensembleType": "NPT",
    "thermostatType": "nose-hoover 100.0",
    "barostatType": "nose-hoover 1000.0",
    "timeStepFs": 1.0,
    "integrationAlgorithm": "Velocity-Verlet",
    "cutoffDistanceAng": 10.0,
    "longRangeElectrostatics": "PPPM 1.0e-4",
    "outputFrequencyStep": 1000,
    "minimizationParams": {
      "method": "cg",
      "energyTol": 1e-4,
      "forceTol": 1e-6,
      "maxIter": 10000
    },
    "equilibriumParams": {
      "nvtSteps": 200000,
      "nptSteps": 500000,
      "temperatureTarget": 298.15,
      "pressureTarget": 1.0
    },
    "productionParams": {
      "totalSteps": 5000000,
      "samplingMethod": "continuous",
      "dumpFrequency": 1000,
      "thermoFrequency": 100
    }
  },
  "hardwareConfig": {
    "hardwareUsed": "GPU",
    "cpuCores": 16,
    "gpuInfo": "NVIDIA A100 40GB",
    "hardwareEnvironment": "GPU 16核 + A100"
  },
  "randomSeed": 12345,
  "taskDescription": "测试不同温度下电导率"
}
```

**响应** (202 Accepted):

```json
{
  "code": 202,
  "message": "任务已创建，正在自动化建模中",
  "data": {
    "jobId": 10001,
    "status": "PENDING",
    "createTime": "2026-06-03T15:00:00"
  }
}
```

> 任务创建后会依次进入 `PENDING` → `RUNNING` → `COMPLETED/FAILED`。前端可通过轮询或 WebSocket 获取状态更新。

## 9. 公共错误码

| code | 含义                               |
| ---- | ---------------------------------- |
| 200  | 成功                               |
| 201  | 创建成功                           |
| 202  | 已接受（异步任务）                 |
| 400  | 请求参数错误                       |
| 401  | 未认证或 Token 失效                |
| 403  | 无权限                             |
| 404  | 资源不存在                         |
| 409  | 资源冲突（如重名）                 |
| 422  | 业务校验失败（如配方电中性不通过） |
| 500  | 服务器内部错误                     |

**统一错误响应格式**:

```json
{
  "code": 422,
  "message": "体系电荷不平衡，总电荷为 +0.5e",
  "timestamp": "2026-06-03T16:00:00"
}
```
