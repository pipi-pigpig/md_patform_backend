## 一、MoltemplateController（3个接口）

### 1. POST /api/moltemplate/calculate
**接口名称**：创建建模任务
**描述**：根据配方配置创建Moltemplate建模任务

**请求参数**：
```json
{
  "components": [
    {
      "moleculeName": "EC",
      "count": 100,
      "molFile": "EC.mol"
    }
  ],
  "temperature": 300,
  "pressure": 1.0,
  "boxSize": {
    "x": 50.0,
    "y": 50.0,
    "z": 50.0
  }
}
```

**Query参数**：
- userId (可选，Long) - 用户ID
- jobId (可选，Long) - 任务ID

**响应结构**：
```json
{
  "success": true,
  "jobId": 123456789,
  "userId": 1,
  "configPath": "/path/to/config.json",
  "message": "配方配置已保存，准备执行建模"
}
```

---

### 2. GET /api/moltemplate/status/{jobId}
**接口名称**：查询建模任务状态
**描述**：查询指定任务的建模状态

**路径参数**：
- jobId (Long) - 任务ID

**响应结构**：
```json
{
  "jobId": 123456789,
  "userId": 1,
  "configExists": true,
  "status": "READY",
  "configPreview": "..."
}
```

---

### 3. POST /api/moltemplate/execute/{jobId}
**接口名称**：执行建模任务
**描述**：执行指定任务的Python建模脚本

**路径参数**：
- jobId (Long) - 任务ID

**响应结构**：
```json
{
  "success": true,
  "jobId": 123456789,
  "userId": 1,
  "message": "Python建模脚本已启动",
  "processId": 12345
}
```
