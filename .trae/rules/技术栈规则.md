# 技术栈规则

## 一、整体架构

本项目采用 **Spring Boot + Python 混合架构**，充分发挥各自优势：

| 技术栈 | 负责领域 | 优势 |
|-------|---------|------|
| **Spring Boot (Java)** | 业务逻辑、后端开发、API服务、数据库操作 | 企业级开发成熟、生态丰富、类型安全 |
| **Python** | 科学计算、外部工具调用、分子动力学模拟 | 科学计算库丰富、与MD工具集成方便 |

## 二、Spring Boot技术栈

### 2.1 核心框架

| 框架/库 | 版本 | 用途 |
|--------|------|------|
| Spring Boot | 3.x | 应用框架 |
| Spring Data JPA | - | 数据库操作 |
| Spring Security | - | 安全认证 |
| Spring WebSocket | - | 实时通信 |
| Lombok | - | 代码简化 |

### 2.2 数据库

| 技术 | 用途 |
|------|------|
| MySQL 8.0 | 主数据库 |
| Redis 7.x | 缓存、会话存储 |

### 2.3 Docker集成

| 库 | 用途 |
|------|------|
| docker-java | Java Docker客户端，用于操作容器 |

**Docker连接配置（Windows）：**
```
npipe:////./pipe/docker_engine
```

### 2.4 代码规范

1. **所有Service类必须添加详细注释**
2. **使用PathUtil生成所有文件路径，禁止硬编码**
3. **使用AtomicFileService进行原子文件写入**
4. **异常处理必须记录详细日志**

## 八、混合架构调用模式

### 8.1 Java调用Python

```java
// 通过DockerService在容器中执行Python脚本
dockerService.executeCommandInContainer(
    "md_engine",
    Arrays.asList("python3", "/workspace/scripts/modeling/run_modeling.py", "--mode", "packmol"),
    "/workspace"
);
```

### 8.2 Python调用外部工具

```python
# 通过subprocess调用Packmol
result = subprocess.run(
    ["packmol"],
    stdin=open("packmol.inp", "r"),
    cwd=work_dir,
    capture_output=True
)
```

## 十、日志规范

### 10.1 Java日志

```java
// 使用Slf4j
log.info("[模块名] 操作描述: {}", 参数);
log.error("[模块名] 错误描述: {}", 错误信息);
```

### 10.2 Python日志

```python
# 使用logging
logger.info("[模块名] 操作描述")
logger.error("[模块名] 错误描述: %s", 错误信息)
```

## 十一、版本控制规范

1. **Git提交信息格式**：`[模块] 操作描述`
2. **分支命名**：`feature/功能名`、`fix/问题描述`
3. **禁止提交临时文件和日志文件**
