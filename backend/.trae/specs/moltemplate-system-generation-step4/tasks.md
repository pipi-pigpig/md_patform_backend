### 修复后的正确system.lt文件格式示例

```moltemplate
# Moltemplate system description file
# Generated by modeling system
# Force field: oplsaa
# Total molecules: 600
# Total molecule instances: 600
# Box size: 48.00 x 48.00 x 48.00 Å

import "../../../../system_templates/molecule_templates/DMC/DMC.lt"  # 分子模板
import "../../../../system_templates/molecule_templates/EC/EC.lt"  # 分子模板
import "../../../../system_templates/molecule_templates/LI/LI.lt"  # 分子模板
import "../../../../system_templates/molecule_templates/PF6/PF6.lt"  # 分子模板

# 创建分子实例
dmc1 = new DMC
dmc2 = new DMC
...
ec1 = new EC
ec2 = new EC
...
li1 = new Li   # 注意：类名是Li（大小写敏感）
li2 = new Li
...
pf61 = new PF6
pf62 = new PF6
...

write_once("Data Boundary") {
  0.0  48.000000  xlo xhi
  0.0  48.000000  ylo yhi
  0.0  48.000000  zlo zhi
}
```

### 关键改进点

1. **符合Moltemplate规范**：生成的文件完全遵循Moltemplate语法要求
2. **正确的相对路径**：从inputs目录到system_templates使用正确的4级上级目录
3. **逐个实例创建**：每个分子实例单独创建，避免数组语法问题
4. **自动坐标处理**：不再手动写入坐标，让moltemplate自动处理
5. **类名兼容性**：支持常见的类名大小写变体映射
